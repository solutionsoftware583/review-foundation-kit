# ReviewVala UI Foundation

Create the complete UI/UX-only prototype for ReviewVala™, an original premium global review-management SaaS powered subtly by Software Vala™ — The Name of Trust. Build the complete high-level visual product foundation described: role-aware dashboard, unified Reviews inbox/detail, Response Center, Ratings, Analytics, Alerts, Locations, Team, Reports, Settings; global search, notifications, business selector/profile; multi-business/location and collaboration concepts; responsive desktop/tablet/mobile designs, loading/empty/error states, tooltips and subtle professional motion. Use realistic mock data only. Do not build backend, database, API integrations, authentication, or production logic. Ensure it feels original, premium, trustworthy, enterprise-ready, and easy for non-technical users, not a clone of other review tools.
